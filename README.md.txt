Airbnb NYC 2019 Ð Exploratory Data Analysis (EDA) & Dashboard ProjectProject OverviewThis project focuses on performing Exploratory Data Analysis (EDA), data cleaning, business analysis, and dashboard creation using the Airbnb NYC 2019 dataset in Microsoft Excel.The project was developed as part of an internship task to demonstrate practical skills in:* Data Wrangling* Data Cleaning* Exploratory Data Analysis* Pivot Table Analysis* Correlation Analysis* Dashboard Design* Business Insight GenerationTools Used* Microsoft Excel* Pivot Tables* Pivot Charts* IF Functions* Scatter Plots* Dashboard Design TechniquesDataset InformationDataset: Airbnb NYC 2019The dataset contains information about:* Airbnb listings* Hosts* Room types* Pricing* Reviews* Availability* Borough locations in New York City
Project Workflow1. Data DictionaryCreated a data dictionary to understand:* Column names* Data types* Business meaning of attributes2. Data Quality AssessmentPerformed data quality checks to identify:* Missing values* Duplicate records* Outliers* Encoding inconsistenciesKey Findings* Missing values existed in:o nameo host_nameo last_reviewo reviews_per_month* Outliers identified in:o priceo minimum_nights3. Data CleaningApplied various cleaning techniques:* Replaced missing values in reviews_per_month with 0* Removed extreme outliers* Verified duplicate records* Handled data inconsistenciesExcel IF functions were used to create categorized and cleaned fields for analysis.
4. Exploratory Data Analysis (EDA)Performed descriptive and analytical exploration using:* Pivot Tables* Pivot Charts* Summary Statistics* Scatter Plot Analysis5. Business Questions AddressedThe project answered several business questions such as:* Which borough has the highest number of Airbnb listings?* Which room type has the highest average price?* Which room type is most common in NYC?* Which borough has the highest average availability?6. Correlation AnalysisPerformed relationship analysis between:* Price and AvailabilityScatter plots were used to identify trends and relationships between variables.7. Dashboard CreationDesigned a static Excel dashboard containing:* KPI Cards* Pivot Charts* Business Insights* Comparative VisualizationsDashboard Components:* Listings by Borough* Average Price by Room Type* Room Type Distribution* Availability AnalysisKey Insights* Manhattan contains the highest number of Airbnb listings.* Entire home/apartment listings have the highest average prices.* Private rooms and entire homes dominate the market.* Staten Island shows relatively high average availability.* Data cleaning significantly improved dataset quality for analysis.Files Included* Raw Data* Data Dictionary* Data Quality Assessment* Cleaned Dataset* EDA Summary* Business Questions* Pivot Tables* Correlation Analysis* Dashboard* InsightsSkills Demonstrated* Data Wrangling* Data Cleaning* Exploratory Data Analysis* Pivot Table Analysis* Correlation Analysis* Dashboard Design* Business Intelligence Reporting* Excel Data VisualizationLearning OutcomesThrough this project, I improved my understanding of:* Real-world data cleaning workflows* Business-oriented analysis* Dashboard presentation techniques* Data visualization best practices* Analytical thinking using ExcelAuthorAjay Nath
